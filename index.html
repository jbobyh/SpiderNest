SPIDER NEST

Найди выход. Не дай паукам добраться до тебя.

// ПРАВИЛА //

WASD — движение игрока
ЛКМ — стрелять (удержание для автострельбы)
1 / 2 — выбрать слот; Q — чередовать слоты; F — подобрать/переключить оружие
Оружие 🔫 — подберись вплотную чтобы подобрать. Пистолет — 1 точная пуля. Дробовик — 3 пули с разбросом. Револьвер — 1 пуля, урон 40. Карабин — очередь из 3 пуль
3 жизни — начальное количество. Трать на открытие дверей
ПКМ — открыть перегородку (–1 жизнь) или закрыть (+1 жизнь). Закрыть можно любую клетку кроме той, где находится игрок
Содержимое — видно в соседних закрытых комнатах
Сердечки — собери для +3 жизней (коснись). Разное количество на каждом уровне
Ключи 🔑 — собери все ключи, чтобы разблокировать выход (2-4 в зависимости от уровня)
Пауки — в некоторых комнатах. Открытие выпускает их! Уничтожай из дробовика!
Зелёная клетка — выход! Собери все ключи и нажми F на клетке выхода, чтобы уйти
Чёрные клетки — закрыты навсегда, больше не открыть
